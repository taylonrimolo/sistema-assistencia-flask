# Sistema de Ordem de Serviço de Informática 💻🛠️

Aplicação web desenvolvida para gerenciar o fluxo de atendimento e manutenção de computadores em uma assistência técnica de TI.

## 🚀 Tecnologias Utilizadas
- **Python & Flask:** Criação do servidor e rotas do back-end.
- **HTML5 & CSS3:** Estrutura e estilização da interface de usuário.
- **Conceitos Aplicados:** Suporte Técnico Nível 1[cite: 1], Hardware Troubleshooting[cite: 1] e Gestão de Ativos de TI.

## 📋 Funcionalidades
- Cadastro de novos equipamentos em manutenção (Cliente, Equipamento e Defeito Relatado).
- Listagem dinâmica dos chamados ativos na assistência técnica.
